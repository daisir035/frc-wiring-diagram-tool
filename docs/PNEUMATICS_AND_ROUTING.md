# 气动系统与海报风格出图

目标是用简单操作画出 Team 3161《FRC Control System Diagrams》那种海报风格的气动图：平面色块的元件、按压力分色的气管、红黑双芯电线、虚线分区、带型号说明的标签，以及底部的标题栏和图例。参考：

- 风格说明：https://wiki.team3161.ca/books/branding-implementation-examples/page/2025-frc-control-system-diagrams
- 气动示意图：https://wiki.team3161.ca/uploads/images/gallery/2024-09/frccsd-ps.png

工具栏「气动示例」会打开一份按该参考图布局的完整工程，由 `scripts/build-pneumatics-example.mjs` 生成：

```
node --experimental-strip-types scripts/build-pneumatics-example.mjs
```

## 推荐画法

1. 从元件库「气动」分类拖入元件。每个元件自带默认说明（型号 / 注意事项），会显示在名称下方。
2. 点接口连气管。气管颜色不用手动设：从空压机沿气路自动追踪，空压机到主调压阀之前是储气侧（紫），主调压阀之后是主工作侧（蓝），再经过一个调压阀就是二级工作侧（橙）。电磁阀只由 P 口向 A/B 口传递压力。需要时可以在气管属性里改成手动指定。
3. 走线用「折线」模式加圆角，最接近参考图：拖动线身弯出固定点，每段横平竖直，拐角圆弧过渡。「正交」模式自动寻路，「曲线」模式为样条曲线。
4. 标签可以直接在画布上拖动摆放。属性面板里可以改名称、说明（可换行）、选择上/下/左/右或隐藏。
5. 工具栏「分区」「说明」「标题栏」添加标注：
   - 分区框是带标题的虚线圆角框。拖边框或标题移动，拖右下角调整大小，框内器件照常点选。
   - 标题栏会自动生成图例：只列出本页用到的气管压力侧和导线线规。
6. 打开「出图模式」：隐藏网格和端口圆点，导线改为细实线，背景为白色。这时「导出 PNG」得到的就是海报效果。

## 气动元件

所有气动元件都在 `src/components/PneumaticArtwork.tsx` 里用 SVG 矢量绘制，配色取自参考图：

| 用途 | 颜色 |
|---|---|
| 黄铜接头 | `#b79349` |
| 推入式接头 | `#bcbdc0` |
| 电磁阀阀体 | `#ded6c8` |
| 线圈 | `#818284` |
| 气缸缸体 | `#515153` |
| 储气 / 主工作 / 二级气管 | `#b177b3` / `#6298d1` / `#faab52` |

图形是参照参考图风格自行重画的，没有从图片里裁剪。参考图本身标注为 CC BY（Team 3161）。

元件清单：空压机、储气罐（竖放）、调压阀（带压力表）、压力表、压力开关/传感器（三通座）、安全阀、泄压阀、单电控电磁阀、双电控电磁阀、阀岛电磁阀、三通、REV Pneumatic Hub、CTRE PCM。

气动控制器（PH / PCM）同样是矢量图，尺寸 74 × 180 mm，端子位置按实物排布：
- 空压机输出在左上，压力开关接口在右上；
- 电磁阀通道：PH 左列为 8–15（自上而下），右列为 7–0；PCM 只有右列 7–0；
- CAN（H L H L）和电源输入在底部，导线向下引出。

画布上的端口和图中端子使用同一套坐标（`CONTROLLER` / `controllerChannel`）。

- 外形尺寸是绘图参考值，可在属性面板按实物校准。
- 两个气口重合（硬接头直接拧在一起）视为已连接，也会传递压力。
- 气口只能连气口，每个接口只接一根管，分支要用三通。

## 走线与线束

| 模式 | 行为 |
|---|---|
| 正交 | 自动横平竖直寻路，拐角圆弧，拖动吸附 4 mm 网格 |
| 折线 | 按固定点直线相连，拐角圆弧，不吸附 |
| 曲线 | 样条穿过固定点，两端沿接口法线伸出 |

- 折线和曲线模式下，按住线身拖动就会插入固定点，撤销一次即可还原。双击线路也可以加点。
- 固定点可以锁定：移动器件时位置不变。
- 线束主干同样支持这三种模式。合并线束时只要求中间端子一致，固定点不同不会阻止合并。
- 电源正负线会自动作为双芯线缆绘制，只需规划 + 线的路线。

示例只作制图参考，不做气动仿真、额定压力校验或赛季规则认证。
