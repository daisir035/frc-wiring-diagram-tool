# UI 改造规格（2026-11-18）

目标：简洁、优雅、容易使用。桌面鼠标键盘优先，平板/手机只需可查看、可轻改。界面仅中文，用词以 `GLOSSARY.md` 为准。

视觉参考：Codex 桌面版。

## 已解决的痛点

- 找器件、放置器件不顺手
- 连线难用（端口难点中、不知道能拖、取消不清楚）
- 顶部全是图标、常用操作藏在菜单里
- 整体粗糙不统一

## 阶段 1：视觉规范

- 配色：黑白单色。界面强调色为近黑（slate-900 一族），以语义色名 `accent` 引用，不再直接使用 teal。中性色为 slate。
- 画布选中态单独用天蓝 `#0ea5e9`（选中框、导线选中光晕），界面其余部分不用彩色。
- 字号：正文 13px，次要 12px，最小 11px。
- Codex 风格：
  - 窗口底色浅灰，画布与检查器是浮起的白色圆角卡片，四周约 8px 间隙，淡边框或淡阴影，无硬分隔线。
  - 列表项无边框无分隔线，悬停/选中为圆角浅灰底。
  - 分组标题小号灰字；16px 细线图标；按钮以幽灵按钮为主；主按钮黑底白字圆角。
  - 深色模式暂不做。
- 空画布只显示点阵网格，无卡片、无文字、无按钮。示例与导入底盘图只在"文件"菜单。
- 说明文字：
  - 删除所有"怎么操作"的说明段落。
  - 状态/警告保留但压缩成几个字（如"⚠ 需重新校准"）。
  - 保留：错误提示、悬停 tooltip、菜单里的快捷键提示。
- 用词统一："器件""器件库"，不再使用"元件"。

## 阶段 2：布局骨架

```
┌ 侧栏 ───────────┐ ┌ 画布卡片 ────────────────────────────────────┐
│ 工程名 ▾      ⇤ │ │                         ↶ ↷  ⚙视图  [导出 ▾] │
│ [器件库 | 连接] │ │                                               │
│ 🔍 搜索          │ │            ┌──────────────────┐   ┌ 检查器 ┐ │
│ 控制器  ▸       │ │            │⟳ 🔒 🗑 ⤳ ● │   │(选中才 │ │
│ 电机    ▸       │ │            └──────────────────┘   │ 展开)  │ │
│ …               │ │                                    └────────┘ │
│ ≡ 文件          │ │ 页1 页2 +    ▸ ✋ T ●新线颜色     − 100% + ⊡  │
└─────────────────┘ └───────────────────────────────────────────────┘
```

- 无顶栏。
- 左侧单层宽侧栏（约 240–260px），可整体收起：
  - 顶部：工程名 ▾（切换/新建/重命名/关闭工程）
  - "器件库 | 连接"分段切换及对应内容
  - 底部"文件"菜单：导入工程、导入底盘图、导入自定义器件、示例、BOM 导出设置、清空页面
- 画布卡片右上角悬浮：撤销、重做、视图菜单（出图模式、标签、网格）、导出 ▾（PNG、BOM Excel、工程文件）。
- 画布卡片底部：左页签，中绘制工具（选择、平移、标注 ▾、新导线颜色），右缩放。
- 选中对象旁的浮动工具条：旋转、锁定、删除、重新布线、颜色。多选时只显示对全部选中对象都适用的操作，并显示"已选 N 项"。
- 右侧检查器只在有选中对象时展开，未选中时收起。

## 阶段 3：交互

- 放置器件：
  - 拖拽（保留）
  - 单击进入放置模式：器件影子跟随鼠标，点击落下，Esc 取消
  - `/` 或 `Ctrl+K` 快速搜索，回车放在鼠标位置
- 连线：
  - 从端口拖出连线更显眼，吸附半径加大到约 18px 屏幕像素
  - 连线中退格 = 后退一步（撤掉起点或最后一个拐点），Esc = 整体取消
  - 点击空白处仍为取消
  - 不加连线状态提示条
- 端口样式维持现状（已用原型比较过方形焊盘、圆点类型色、极简淡入）。

## 验收

每阶段：`npm test`、`npm run lint`、`npm run build` 全部通过，并附改造前后截图对比。
