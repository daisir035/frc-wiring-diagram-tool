# 气动元件与自由布线设计

基于 `frc-main-backup-20260906`。目标是在现有 React/TypeScript/SVG 编辑器里绘制 FIRST 气动手册风格的完整电气与气路图，兼容既有工程。

## 已明确的需求

- 更自由地拖拽线路，能够设置固定点，拐弯具有可调弧度。
- 气缸可选择不同缸径及长度，尺寸以 AndyMark 产品资料为准。
- 元件图片优先从用户提供的 PDF 提取，缺失的自行绘制。
- 添加基础气动元件、独立气路、电气控制连接及完整示例。

## 实现选择

沿用 SVG 和现有路径计算、历史记录、工程存储。避免引入第二套画布或路由库。保留正交布线作为默认选项，增加自由折线路径和圆角半径。完整自动避障路由需要额外算法且不能替代用户手动布局，本次不采用。

### 路径交互

- 属性面板选择正交或自由路径，设置圆角半径；自由模式拖动不强制吸附。
- 在线路上增加路径点，拖动调整，允许删除。路径点默认是纯几何控制点，不显示为 Wago 或其他连接器。
- 点可锁定在世界坐标；移动端点器件保留固定点。解锁后允许直接拖动。整体复制图纸时点随副本平移。
- 自由模式按点序连接并在拐角切圆，短线段自动限制半径，重复点和折返不得产生 NaN。
- 线束主干的路径和半径在成员间保持一致，单线引入/引出段保留各自路径。拆束保留可见走向。
- 拖拽作为一次撤销操作。编辑命中、连接器位置和导出使用一致几何。

### 气动元件与气路

新增压缩机、储气罐、调压阀、压力表、压力开关、安全阀、手动泄压阀、单/双电磁阀、双作用气缸、三通与分气块，并补齐 PH/PCM。

气口独立于电口，禁止交叉连接；气管不应用 AWG 或电气端子规则。管径和压力侧作为气管属性，材料表分别统计电线和气管。调压阀明确入口与出口，电磁阀明确供气、工作口与排气口。分支通过接头或分气块表达，避免任意无限共用物理接口。

示例包含高压储气侧、调压后的工作侧、气缸以及控制器到压缩机/压力开关/电磁阀的电连接。参考手册为 Rev. Jan 2023，不将示例标为赛事合规认证。

### 气缸与素材

“长度”默认实现为可选行程，同时显示收缩总长；二者不能混用。仅将有 AndyMark 产品或尺寸图佐证的缸径、行程、收缩总长和外径作为预设，记录型号和来源；未查明的尺寸不能伪称实测。切换型号更新外框及端口位置，保留实例连线。

素材来源目前按用户提供的 PDF 理解。优先提取内嵌原图并裁切元件、去除背景；无法独立提取或缺失的元件再绘制。保留来源、页码及裁切说明。气缸图形随规格调整，避免把同一张图片拉伸后当作准确尺寸图。

## 验证与兼容

旧工程未设置新字段时保留原有渲染和行为；旧路径点保留原来的端子语义，通过显式新类型区分。新增字段通过导入校验，保存、加载、复制、撤销和导出完整保留。覆盖气电误接、圆角退化、锁点移动、线束拆分、气缸切换和材料表。
