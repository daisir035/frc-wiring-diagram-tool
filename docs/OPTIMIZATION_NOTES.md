# 本轮优化与验证记录

日期：2026-09-20。基于 FRC 版本 `86835e0` 的本地工作区；未切换或合并分支，未改 Vercel 项目配置。

## 已完成

- **保存与恢复**：将工作区从同步 localStorage 写入迁至 IndexedDB；保留旧存档、当前/上一版快照及损坏数据。串行写入、防抖、拖动时延后保存，显示真实保存状态、失败与重试入口。覆盖“写入途中撤销回旧快照”的竞态。
- **存档校验**：独立 schema/迁移模块，校验类型、版本、ID、器件与端口引用、配对关系及可选字段。错误文件明确拒绝；兼容旧源文件与历史端口迁移；v1 多工程导入不再只取首个工程。
- **数据保护**：示例新增工程；被任何工程页面引用的自定义器件禁止删除；源文件只携带当前工程需要的自定义定义；导入时处理定义与工程 ID 冲突。
- **撤销重做**：最多 80 步，覆盖完整工作区；连续拖动按一次编辑合并，平移和缩放不单独占用撤销步骤。
- **接线与 BOM**：拒绝不兼容的端口/可识别的接口连接；显式配置自定义 CAN、电源端口配对；已有错误连接和直接配电通道的部分保险丝/线规问题进入 BOM 待核对项。
- **交互**：弹窗焦点限制、Escape 关闭与焦点恢复；输入框/弹窗快捷键隔离；保险丝只接受正常左键或键盘操作；修复 Shift 拖动选择；扩大端口命中区并按最近显示端口消除密集端口抢点。
- **图片**：约束上传尺寸、压缩输出、校验链接协议，清理对象 URL，处理上传取消与错误。
- **性能与结构**：复用双芯线缆几何，减少路由候选排序计算；平移缩放不重复锚定全部线束。提取存档、存储、历史和图片处理模块；移除不需要的路由及模板 UI/依赖；保留 Excel 按需加载。
- **文档**：替换默认模板 README，说明使用、保存范围、开发验证及 BOM 限制。

## 验证结果

最终标准检查：**140/140 测试通过**（原 80 项），`npm run lint`、`npm run build`、`git diff --check` 均通过。依赖审计由原 14 个受影响依赖项降为 0；这代表审计数据库中未检出已知漏洞，不代表全部应用风险已排除。

生产入口 JS 为 498.33 kB / gzip 161.28 kB；CSS 从 91.00 kB 降至 30.44 kB（gzip 6.05 kB）；Excel 独立 chunk 为 943.94 kB / gzip 274.07 kB。构建仍提示 Excel chunk 体积超过 500 kB，这是按需加载模块的已知限制。

浏览器验证涵盖：新增器件、撤销/重做、自动保存后刷新、示例保留原工程、弹窗中 Delete 不影响画布、保险丝右键不改额定值、拒绝不兼容连接、合法源文件导入、损坏文件拒绝、自定义器件引用保护，以及生产文件挂载于子目录后的访问。最终构建中另验证了 58% 缩放下 roboRIO 密集 DIO 端口的实际坐标点击，焦点正确落在 DIO 0；生产页面错误日志为空。

真实 Excel 导出函数生成了 14,434 字节 XLSX 并从磁盘重新读取，核对 4 张工作表、线路数、长度及公式缓存、告警和文本安全；ZIP 完整性检查通过。浏览器实际导出的 `审查导入工程-BOM.xlsx` 已在下载目录找到（13,606 字节），重新读取确认 4 张工作表及测试板卡数据存在；浏览器下载落盘与文件可读性均已验证。

几何性能以基准 `86835e0` 对比，先通过 512 种路径及两组完整线束输出一致性检查，再预热 10 次、交替采样 40 次取中位数：

| 单芯导线数 | 原几何计算 | 当前几何计算 | 耗时降低 |
| --- | ---: | ---: | ---: |
| 200（100 条双芯线缆） | 5.63 ms | 2.51 ms | 55.4% |
| 500（250 条双芯线缆） | 10.93 ms | 4.56 ms | 58.2% |

这是合成几何测试，不包含浏览器绘制、输入和存储，绝对数值随设备与后台负载变化。运行方式见 README。
